Mode d'emploi

1. Dans Canva

Partager → Télécharger → PDF Standard. Les liens ajoutés dans Canva (texte ou image avec un lien) sont conservés et repris automatiquement ici.

2. Ici, sur l'iPad

  • Ouvrir le PDF depuis l'app Fichiers.
  • Les zones cliquables apparaissent en violet. Touchez-en une pour changer l'adresse ou la supprimer ; faites-la glisser pour la déplacer ; tirez le rond blanc pour l'agrandir.
  • ＋ Dessiner un lien : glissez le doigt sur la zone à rendre cliquable (un bouton, un texte, un logo…), puis tapez l'adresse : site web, e-mail ou téléphone.
  • Décochez Inclure pour retirer une page du mail.
  • Couleur autour du visuel : « Auto » reprend la couleur du bord du PDF pour un rendu sans démarcation.

3. Créer et envoyer

  1. Créer le mail affiche l'aperçu exact du mail.
  2. Envoyer le mail vers mon PC… : choisissez Outlook ou Mail et envoyez-le à votre adresse pro (ou AirDrop / OneDrive).
  3. Sur le PC, double-cliquez la pièce jointe .eml : Outlook ouvre un nouveau mail prêt à partir. Ajoutez les destinataires → Envoyer.

Bon à savoir

  • Le visuel est intégré en images haute définition découpées : couleurs, polices et mise en page restent identiques au PDF dans Outlook, Gmail, sur iPhone… Les zones avec un lien sont des images cliquables.
  • Le texte du PDF est repris comme texte alternatif des images (affiché si les images sont bloquées, lu par les lecteurs d'écran).
  • Si Windows n'ouvre pas le .eml avec Outlook : clic droit → Ouvrir avec → Outlook.
  • Avec le nouvel Outlook, si le mail s'ouvre en lecture seule : ouvrez cet outil sur le PC, puis Copier le mail et collez-le (Ctrl+V) dans un nouveau message.
  • Gardez le mail sous ~10 Mo : choisissez la qualité « Légère » si le PDF a beaucoup de pages.
